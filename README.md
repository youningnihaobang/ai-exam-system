# AI 智能试卷模拟系统

基于 Node + **CodeBuddy Agent SDK**（`@tencent-ai/agent-sdk`）的网页版试卷模拟工具：AI 出题 → 在线答题 → AI 评卷 → 错题改错。

## 功能

- **生成试卷（两种方式）**：
  1. **按题型配置**：选择科目与难度，自由组合 9 种题型与题量、分值，可填写附加要求，AI 生成结构化试卷（含答案、解析、知识点、建议用时）。
  2. **按大纲 / 文档**：粘贴大纲文字，或上传 `PDF / Word(.docx) / TXT / Markdown` 文档（可多选、可拖拽）；可先点「AI 分析大纲」让 AI 自动识别科目、难度与题型题量并回填表单，确认后再生成。系统解析正文后交给 AI 依据大纲命题；题型题量可留空由 AI 自定，也可指定。生成后回显大纲来源、解析字数与已覆盖知识点。**解析出的正文会自动保存进「解析文档库」**（JSON 文档数据库），可随时查看全文、再次用于命题或删除。

  | 题型 | 说明 | 默认分值 | 评分方式 |
  | --- | --- | --- | --- |
  | `single` 单选题 | 一个正确选项 | 3 | 系统判定 |
  | `multiple` 多选题 | 至少两个正确选项 | 4 | 系统判定 |
  | `judge` 判断题 | 判断陈述对错 | 2 | 系统判定 |
  | `blank` 填空题 | 支持多空，忽略大小写与标点 | 3 | 系统判定（判错后 AI 复核） |
  | `term` 名词解释题 | 解释概念，按要点给分 | 4 | AI 评分 |
  | `short` 简答题 | 按关键步骤/要点给分 | 8 | AI 评分 |
  | `discriminate` 辨析题 | 先判断正误再说明理由 | 6 | AI 评分 |
  | `material` 材料分析题 | 含材料原文，需结合材料作答 | 12 | AI 评分 |
  | `essay` 论述题 | 论点 + 论据 + 结论 | 15 | AI 评分 |

  3. **科目库（一次解析，反复命题）**：按大纲生成一次后，科目名称、大纲原文、AI 识别的题型结构与历年真题考点自动归档到 `data/db.json` 的 `subjects` 集合；以后在「科目库」下拉选中即可直接生成，不必再上传 / 解析大纲。也可点「保存 / 更新」手动归档，或「删除」档案（不影响已生成的试卷）。
- **参考历年真题（50% 真题考点 + 50% 大纲范围）**：勾选后命题前先用 `WebSearch / WebFetch` 联网检索该科目历年真题考点，再按比例（默认 50/50）分配：一半考真题高频考点，一半考大纲范围内真题低频或未考的知识点。检索结果随科目档案保存，下次复用；需要最新时勾「重新联网检索」。
- **参考历年真题（自有资料，重点学「提问方式」）**：可直接上传真题文档（PDF / Word / TXT / Markdown，可多选）或粘贴真题原文，命题时把真题原文交给 AI，要求它先归纳真题的**设问角度、题干措辞与指令词、选项与陷阱设计、作答要求、题型分值配比**，再模仿这些提问方式出题（知识点可以不同，问法要向真题靠拢），同时严禁照抄原题题干与数据。两种学习重点可选：「重点学习提问方式」（默认）或「提问方式 + 真题考点并重」。真题原文随科目档案归档，之后从科目库命题会自动复用；上传的真题文档解析结果同样存入「解析文档库」，可在文档库里一键选用于命题，无需重复上传。
- **在线答题（单题模式）**：一次只显示一道题，一屏一题，不用整卷下滑：
  - 顶部题号答题卡：已作答高亮、当前题高亮、显示「已答 X / Y 题」，点题号可跳转；
  - 底部常驻「上一题 / 下一题」，最后一题变成「提交并评卷」，切题自动回到顶部；
  - 支持键盘 `←` `→` 切题（输入框内不拦截）；
  - 单选 / 判断题选完自动进入下一题，可在答题页关闭该开关（记忆在本地）；
  - 题型覆盖选项、判断、多空填空、代码框与简答 / 论述作答区。
- **智能评卷**：
  - 客观题本地判定（单选/多选/判断精确比对，填空忽略大小写与标点差异）；
  - 填空题本地判错时交给 AI 复核，避免同义答案被误判；
  - 简答题由 AI 按要点/步骤给分（支持 0.5 分粒度）并写失分点评；
  - 生成总分、正确率、整体评价、薄弱知识点与复习建议。
- **后台评卷 + 串行队列**：提交答卷后服务端立即返回，评卷在**服务端后台**执行，页面不再卡在等待遮罩里：
  - 所有评卷（含错题变式题批改）进同一条队列，**同一时刻只评一份**，其余按提交顺序排队；
  - 前端只轮询任务进度，答题页显示「队列中第 N 位 / AI 正在评卷 · 已输出字数」，顶栏常驻「后台评卷中」提示，可随意切换页面；
  - 同一份试卷已有未完成的评卷任务时直接复用，不会重复排队；
  - 评卷完成后自动刷新试卷列表、错题本与做题历史，并弹出提示。
- **做对即消灭错题**：评卷后先处理做错的题（入本 / 累计错误次数），再处理做对的题：
  - 同题错题标记为「已掌握」（记录 `masteredAt` 与这次做对的答案）；
  - **该知识点算掌握**：错题本中同知识点（含「中国式现代化」覆盖「中国式现代化中国特色」这类被包含的表述）且本轮没做错的其它错题一并标记已掌握，并记录 `masteredByKnowledge`；
  - 若某道题这次又做错，即便之前已掌握也会重新回到错题本（累计错误次数，不再重复建条目）；
  - 结果页对应题目显示「知识点已掌握 · 消灭 N 道错题」标签，总览处提示本次消灭了几道错题；错题卡片标注「知识点「X」做对后自动掌握」。
- **错题本与改错**：评卷后错题自动入本，**按「科目 → 知识点」两级分组**（科目组下再按知识点分组，同一知识点的错题合并为一组，两级都能折叠；知识点互相包含的细碎表述会归并到更宽泛的知识点，无知识点的归入「未标注知识点」），左栏可按科目筛选，支持
  - AI 讲解（解题思路 / 易错点 / 必须记住 / 一道巩固题）；
  - 生成 3 道同类变式题并再次作答批改，全部正确即可标记已掌握；
  - 错误次数统计、已掌握/未掌握筛选、手动标记与删除。
- **复习 / 闪卡（间隔重复）**：把错题本一键同步成闪卡，在「复习」页按到期队列自测 —— 先自己回忆，再点「显示答案」对要点，然后三档评分：
  - **忘了**：当天再来一遍，ease 下调；
  - **模糊**：间隔 ×1.2（首次 1 天）；
  - **记得**：1 天 → 3 天 → 按 ease（默认 2.5）递增，上限 180 天；
  - 顶栏「复习」显示今日待复习张数；支持按科目筛选、查看全部卡片（到期日 / 间隔 / 连续记得 / 遗忘次数）与单张删除；同一道错题只保留一张卡片，重复同步不会重置已有排期。
- **做题历史**：独立的「做题历史」页，记录每一次作答：
  - 总览：累计**做题次数**、**最近做题时间**、**最近成绩**、平均正确率、覆盖的试卷与科目数；
  - 按科目统计：每个科目的做题次数、最近一次时间与成绩、最好成绩、平均正确率（左栏可按科目筛选）；
  - 逐次记录：试卷名、得分 / 总分、正确率、做题时间，点「查看」可回看该次答卷的逐题解析；
  - 试卷列表与答题页同步显示该卷「已做 N 次 · 最近 X 分 · 最好 Y 分」，答题页底部列出本卷历次记录。

## 快速开始

```bash
npm install
cp .env.example .env
npm start          # 打开 http://localhost:3000
```

开发模式：`npm run dev`（node --watch 自动重启）。

### 认证（二选一）

1. **使用登录凭据**：在终端执行 `codebuddy login` 完成登录，`.env` 无需填写 Key。
2. **使用 API Key**：在 `.env` 中填写 `CODEBUDDY_API_KEY`（获取地址：<https://www.codebuddy.cn/profile/keys>）；使用中国版 / iOA 版 / 专享版 / 私有化时，需同步设置 `CODEBUDDY_INTERNET_ENVIRONMENT`。

> SDK 依赖 CodeBuddy CLI：若 `codebuddy` 不在 PATH 中，SDK 会使用包内置的可执行文件；也可通过 `CODEBUDDY_CODE_PATH` 显式指定。

### 按大纲 / 文档生成试卷

- 支持格式：`PDF`、`Word(.docx)`、`TXT / Markdown`；单个文件 ≤ 10MB，一次最多 8 个，可与粘贴的文本同时使用。
- 解析后的正文拼接后一次性交给 AI，超过 60000 字符自动截断（生成结果会给出提示）。
- 每份文档解析出的正文都会保存进「解析文档库」（`documents` 集合，同一内容不会重复入库），可在生成页查看全文、一键「用于命题」或删除；生成时按 `docId` 复用，不需要重复上传。
- 「参考历年真题（自有资料）」：上传真题文档或粘贴真题原文后，生成时会把这些原文交给 AI 学习其**提问方式**（设问角度、题干措辞、选项与陷阱、作答要求、题型分值配比），模仿问法而非照抄原题；真题原文超过 12000 字符自动截断。真题原文会随科目档案归档，从科目库命题时自动复用。
- 已知限制：
  - 旧版 `.doc` 不支持，请用 Word 另存为 `.docx`；
  - 扫描版 / 图片型 PDF 提取不到文字，上传后会提示，请改用文本或 Word 文档；
  - PDF 中的复杂公式、表格可能丢失结构，建议在粘贴文本中补充。
- 题型与题量留空时由 AI 依据大纲自行设计（建议 12~30 题、总分约 100 分）；勾选了题型则以勾选为准，与大纲原文冲突时以大纲为准。

## 技术栈

- 后端：Node 18+（ESM）、Express、CodeBuddy Agent SDK（`query()` 单次查询）
- 存储：**JSON 文档数据库**（NoSQL 风格，零依赖）：`data/db/<集合>.json`，一个集合一个文档文件（`papers` / `submissions` / `mistakes` / `subjects` / `documents` / `reviews` / `settings`），内存读写 + 异步串行落盘（先写 `.tmp` 再改名，避免半截文件）。首次启动若发现旧版单文件 `data/db.json` 会自动迁移到集合文件，原文件备份为 `data/db.legacy.json`
- 前端：原生 HTML / CSS / JavaScript 单页应用，无构建步骤
- 文档解析：`multer`（内存上传）+ `pdf-parse`（PDF）+ `mammoth`（docx）+ `iconv-lite`（TXT 编码识别）

### AI 调用约定（`src/ai.js`）

- 使用 `query({ prompt, options })`，通过 `systemPrompt` 传入角色与输出规范，要求模型**只输出 JSON**；
- 任务为纯文本，故限制 `permissionMode: 'plan'`、`allowedTools: []`（不调用任何工具）、`maxTurns: 1`、`persistSession: false`（会话不落盘）；
- 从 assistant 文本流中拼接内容并解析 JSON（兼容 ` ```json ` 代码块），若模型返回 `structured_output` 则优先使用；
- 内置超时中断（AbortController）与认证 / CLI 缺失 / 超时的中文错误提示。

## 目录结构

```
src/
  server.js     # Express 服务入口
  routes.js     # 全部 API（生成试卷 / 评卷 / 错题本）
  queue.js      # 后台任务队列：评卷排队、串行执行、进度与去重
  ai.js         # CodeBuddy Agent SDK 调用封装（JSON 解析 + 超时 + 错误提示）
  prompts.js    # 命题 / 按大纲命题 / 大纲分析 / 评卷 / 讲解 / 变式题 Prompt
  parse.js      # 上传文档解析：PDF / docx / TXT（含编码识别与字数限制）
  normalize.js  # 题目与答案规范化、客观题判定
  db.js         # JSON 文档数据库：集合 / 文档 API、分文件持久化、旧库迁移
  store.js      # 数据访问层（试卷 / 答卷 / 错题 / 科目档案 / 解析文档 / 设置）
public/         # 前端页面
```

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/config` | AI 配置状态 |
| POST | `/api/papers` | AI 生成试卷（按题型配置） |
| POST | `/api/outline/preview` | 解析上传文档，返回字数 / 预览 / `docId`（不调用 AI）；解析出的正文自动存入解析文档库，`kind=past-paper` 表示历年真题 |
| GET | `/api/documents` | 解析文档库列表（`?kind=past-paper&subject=&limit=`，不含全文） |
| GET | `/api/documents/:id` | 文档详情（含解析出的全文） |
| DELETE | `/api/documents/:id` | 删除一份解析文档 |
| POST | `/api/outline/analyze` | AI 分析大纲：识别科目、难度与题型题量建议（`multipart/form-data`：`outline`/`files[]`） |
| POST | `/api/real-exam/analyze` | 联网检索历年真题考点（来源链接、高频考点、概述） |
| GET | `/api/subjects` | 科目库列表（不含大纲原文） |
| GET | `/api/subjects/:id` | 科目档案详情（含大纲原文与真题考点） |
| POST | `/api/subjects` | 新建 / 更新科目档案（按科目名去重） |
| DELETE | `/api/subjects/:id` | 删除科目档案 |
| POST | `/api/papers/from-subject` | 用科目档案命题：复用已存大纲、真题考点与历年真题原文，无需重新上传解析（`usePastPaper=1` 复用档案真题） |
| GET | `/api/ai/progress` | 当前 AI 任务进度（阶段 / 已输出字数 / 已用秒数） |
| POST | `/api/papers/from-outline` | 按大纲 / 文档生成试卷（`multipart/form-data`：`subject`/`difficulty`/`notes`/`outline`/`specs`/`files[]`，历年真题另传 `pastPaperText` / `pastDocIds` / `pastPaperMode=style\|mix`） |
| GET | `/api/papers` | 试卷列表 |
| GET | `/api/papers/:id?mode=exam` | 试卷详情（`mode=exam` 隐藏答案） |
| POST | `/api/papers/:id/grade` | 提交作答，**立即返回后台任务**（评卷在服务端排队串行执行，同一份试卷重复提交会复用原任务） |
| GET | `/api/jobs/:id` | 查询后台任务进度；评卷完成后一并返回 `submission` |
| GET | `/api/jobs` | 队列概况：正在执行的任务 + 排队中的任务 |
| GET | `/api/submissions` | 答卷列表，可用 `?paperId=` 过滤某份试卷的历次答卷 |
| GET | `/api/submissions/:id` | 答卷详情（含逐题明细） |
| GET | `/api/history` | 做题历史：累计次数 / 最近做题时间与成绩 / 按科目与按试卷统计 / 逐次记录 |
| GET | `/api/mistakes` | 错题列表 |
| POST | `/api/mistakes/:id/explain` | AI 讲解错题 |
| POST | `/api/mistakes/:id/variants` | 生成同类变式题 |
| POST | `/api/mistakes/:id/variants/grade` | 变式题批改 |
| PATCH / DELETE | `/api/mistakes/:id` | 标记掌握 / 删除 |
| GET | `/api/reviews` | 复习卡片与统计（`?due=1` 只返回今天到期的，`?subject=` 按科目过滤） |
| POST | `/api/reviews/sync` | 把错题本同步成闪卡（同一道错题只保留一张，排期不重置） |
| POST | `/api/reviews/:id/answer` | 提交复习结果 `forgot` / `fuzzy` / `known`，返回新的间隔与到期日 |
| DELETE | `/api/reviews/:id` | 删除一张复习卡片 |
