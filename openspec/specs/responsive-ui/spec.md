# responsive-ui Specification

## Purpose

定义前端在窄屏（手机浏览器）下的展示与交互契约：视口与安全区处理、单列布局与侧栏收放、横向溢出约束、可点击目标与输入字号，以及常驻操作条的可见性；同时保证桌面宽度下的既有布局与操作方式不被改变。

> 术语：**窄屏** 指视口宽度小于 900 CSS px；**桌面宽度** 指视口宽度不小于 900 CSS px。**支持的最小宽度** 为 320 CSS px。

## Requirements

### Requirement: 视口声明与安全区适配

页面 MUST 声明适配刘海屏 / 圆角屏的视口（覆盖式视口，使内容可延伸到安全区外由 CSS 留白处理）。系统 SHALL 让顶栏、底部常驻操作条、页面主体与浮层各自避开设备安全区：其可交互内容 MUST NOT 落在系统 UI（状态栏、Home 指示条、圆角裁切区）覆盖的范围内。系统 MUST NOT 通过禁用用户缩放（`user-scalable=no` 或 `maximum-scale=1`）来规避适配问题。

#### Scenario: 带安全区的机型上内容不被遮挡

- **WHEN** 在带顶部刘海与底部 Home 指示条的窄屏设备上打开任一页面
- **THEN** 顶栏与底部常驻操作条的可点击内容均完整可见且可点，不被系统 UI 覆盖

#### Scenario: 保留用户缩放能力

- **WHEN** 检查页面的视口声明
- **THEN** 未出现禁止或限制用户缩放的设置，用户仍可双指缩放页面

### Requirement: 窄屏下不产生横向滚动

在支持的最小宽度（320 CSS px）到窄屏上限之间，任一页面的内容区域 MUST NOT 产生横向滚动，页面整体可滚动宽度 MUST NOT 超过视口宽度。唯一例外是自包含的滚动容器（代码块、超长不可断词串），此类内容 MUST 只在自身容器内横向滚动，MUST NOT 撑开页面。

#### Scenario: 最小宽度下逐页浏览

- **WHEN** 视口宽度为 320 CSS px，依次打开生成试卷、答题评卷、做题历史、错题本、复习五个页面
- **THEN** 每个页面的可滚动宽度都不大于视口宽度，不出现左右拖动的横向滚动条

#### Scenario: 代码块与长串自我约束

- **WHEN** 窄屏下渲染含长代码行或连续无空格长串的内容
- **THEN** 该内容在其自身容器内横向滚动，页面整体宽度不变

#### Scenario: 复习与统计类卡片不溢出

- **WHEN** 窄屏下打开「记忆看板」「成绩卡」「挖空回忆」等含固定宽度子项的区块
- **THEN** 这些子项收缩到视口内，不溢出到卡片或视口之外

### Requirement: 窄屏单列布局与可收放的侧栏

在窄屏下，主内容与侧栏 MUST 不再并排：侧栏 MUST 可由用户主动展开与收起，且每个视图首次进入窄屏时侧栏 MUST 处于收起状态，使主内容在首屏即可见。侧栏收起 / 展开的入口 MUST 在窄屏下保持可用（MUST NOT 被隐藏）。在桌面宽度下，两者 MUST 恢复并排的两栏布局。

#### Scenario: 窄屏进入答题页直接看到主内容

- **WHEN** 在窄屏下切到「答题评卷」并选择一份试卷
- **THEN** 题目区在首屏可见，无需先滚过整个科目导航与试卷列表

#### Scenario: 窄屏可收放侧栏

- **WHEN** 在窄屏下点击侧栏收放入口
- **THEN** 侧栏在收起与展开之间切换，页面不产生横向滚动，主内容仍可操作

#### Scenario: 桌面宽度保持两栏

- **WHEN** 在桌面宽度下打开同一视图
- **THEN** 侧栏与主内容并排显示，用户此前保存的收放状态继续生效

### Requirement: 收放状态在断点变化时的稳定性

用户显式设置的侧栏收放状态 MUST 在刷新后保持。视口宽度跨断点变化时，系统 SHALL 保留用户在同一断点下已保存的状态，MUST NOT 用另一断点的默认值覆盖用户的显式选择。

#### Scenario: 窄屏手动展开后刷新

- **WHEN** 在窄屏下把侧栏展开，然后刷新页面
- **THEN** 该视图的侧栏仍为展开状态

#### Scenario: 从窄屏切到桌面宽度

- **WHEN** 在窄屏下收起侧栏后把视口拉宽到桌面宽度
- **THEN** 桌面宽度下的侧栏按桌面自身的已保存状态显示，不受窄屏操作影响

### Requirement: 底部常驻操作条可见且不被遮挡

答题页的底部常驻操作条（上一题 / 下一题 / 提交并评卷）在窄屏下 MUST 始终可见或可到达，并 MUST NOT 被底部安全区、页面内容或系统输入法覆盖而无法点击。

#### Scenario: 长题干滚动时操作条仍可用

- **WHEN** 窄屏下题干与作答区长度超过一屏并向下滚动
- **THEN** 底部操作条的按钮仍然可见且可点击

#### Scenario: 聚焦输入框时操作条不被输入法压住

- **WHEN** 窄屏下聚焦作答文本框并唤起系统输入法
- **THEN** 底部操作条的按钮未被输入法遮挡到不可点击

### Requirement: 输入控件不触发移动端自动缩放

在窄屏下，文本类输入控件（文本输入框、多行文本框、下拉选择）获得焦点时 MUST NOT 引起页面自动放大。该约束 MUST 通过控件自身的字号达成，MUST NOT 依赖禁用页面缩放。

#### Scenario: 聚焦作答框不缩放页面

- **WHEN** 在移动端浏览器中聚焦答题文本框或大纲文本框
- **THEN** 视口缩放比例保持不变，页面不发生跳变

#### Scenario: 表单密度不因字号而溢出

- **WHEN** 窄屏下渲染生成试卷表单的全部字段
- **THEN** 提高字号后各字段仍在视口内正常换行显示，不产生横向滚动

### Requirement: 主要交互控件的触摸目标尺寸

窄屏下主要交互控件——题目导航按钮、筛选条、次级按钮、选项行与文件 / 文档操作按钮——的触摸命中区域 MUST NOT 小于 44×44 CSS px。命中区域可由内边距或透明扩展区达成，不要求视觉尺寸同样放大。同一行内相邻控件的命中区域 MUST NOT 相互重叠。

#### Scenario: 量取题号按钮命中区域

- **WHEN** 窄屏下测量题目导航按钮的可点击区域
- **THEN** 其高度与宽度均不小于 44 CSS px

#### Scenario: 相邻筛选条不误触

- **WHEN** 窄屏下点击一行内某个筛选条（如「全部 / 未掌握 / 已掌握」）的边缘
- **THEN** 命中的是与点击位置对应的那一个，未触发相邻控件

### Requirement: 顶栏在窄屏下全部入口可达

窄屏下顶栏的主导航入口（生成试卷、答题评卷、做题历史、错题本、复习）MUST 全部可达且不被裁切，可点选切换视图；次要入口（模型选择、AI 状态、后台评卷提示）MUST 同样可达。顶栏 MUST NOT 造成页面横向滚动，并 MUST 保持吸顶时不遮挡主内容。

#### Scenario: 最小宽度下切换全部视图

- **WHEN** 视口宽度为 320 CSS px
- **THEN** 五个导航入口都能被点选，切换后对应页面正确显示

#### Scenario: 次要入口仍可用

- **WHEN** 窄屏下需要切换模型或查看 AI 状态
- **THEN** 这两个入口可被打开并正常操作

### Requirement: 动态视口高度适配

窄屏下的页面高度 SHALL 跟随移动浏览器可见视口的变化，地址栏收起或展开时内容 MUST NOT 被截断或出现明显跳动。系统 MUST NOT 仅以固定视口高度常量计算布局可用高度。

#### Scenario: 地址栏收起 / 展开

- **WHEN** 在移动浏览器中上下滚动使地址栏收起再展开
- **THEN** 底部常驻操作条始终停留在可见区域内，内容不被裁切

### Requirement: 桌面端行为不回归

在桌面宽度下，两栏并排布局、侧栏收放入口与状态记忆、单题作答模式与键盘左右方向键切题等既有行为 MUST 保持不变；本次适配 MUST NOT 改变任何接口请求与响应。

#### Scenario: 桌面端既有操作保持

- **WHEN** 在桌面宽度下进入答题页，作答后按键盘方向键切题
- **THEN** 题目正常切换，侧栏收放按钮仍可用且状态被记住

#### Scenario: 接口契约不变

- **WHEN** 对比适配前后的前后端请求
- **THEN** 请求路径、参数与响应字段均无新增或变更

#### Scenario: 可见性开关在两种宽度下都生效

- **WHEN** 「答完自动下一题」开关在桌面宽度下被切换
- **THEN** 该设置继续被记住，并在窄屏下同样生效
